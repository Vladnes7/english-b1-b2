# Английский B1 → B2 — как продолжать работу над сайтом

Файл-инструкция для нового чата / другого ИИ. Прочитай его целиком, прежде чем что-то менять.

## Что это

Тренажёр английской лексики. **Весь сайт — один самодостаточный файл `index.html`**
(~250 КБ): HTML, CSS, JS, словарь и фоновое фото (base64) внутри. Никаких сборок,
зависимостей и внешних запросов — файл открывается двойным кликом и работает офлайн.

- Локальная копия: `~/english-sites/index.html`
- Репозиторий: https://github.com/Vladnes7/english-b1-b2
- Опубликован: https://vladnes7.github.io/english-b1-b2/ (GitHub Pages, ветка `main`, корень)

## Как выложить изменения

`gh` уже авторизован под аккаунтом `Vladnes7`.

```bash
rm -rf /tmp/eng-repo
gh repo clone Vladnes7/english-b1-b2 /tmp/eng-repo
cp ~/english-sites/index.html /tmp/eng-repo/index.html
cd /tmp/eng-repo
git add index.html && git commit -m "описание изменений" && git push origin main
```

Pages пересобирается 20–60 секунд. Проверить, что новое доехало:

```bash
curl -s -L https://vladnes7.github.io/english-b1-b2/ | grep -c "искомая строка"
```

## Разделы сайта

| Вкладка | Что внутри |
|---|---|
| **Учить** | Таблица слов текущего дня (20 шт.) с транскрипцией и галочками |
| **Практика** | Карточки · Пары · Пропуски (вставить слово во фразу) |
| **Тест** | Опрос по словам дня в обе стороны |
| **Повторить** | Умное повторение (SRS): ошибки возвращаются через 1, 3, 7 дней |
| **Фразы** | 200 разговорных фраз, 27 категорий — вне системы дней |
| **Speaking** | Слова с занятий с репетитором, по темам — вне системы дней |
| **Прогресс** | Статистика, теплокарта, экспорт/импорт прогресса |

## Где лежат данные

Три JSON-блока внутри `index.html`, каждый в своём `<script type="application/json">`:

| id | Что | Формат |
|---|---|---|
| `vocab` | 15 уроков по 20 слов | `{"lessons":[{"topic":"…","words":[{"en","ipa","ru","sentence","strans"}]}]}` |
| `phrasebook-data` | 100 фраз | `{"groups":[{"cat":"…","items":[{"en","ru"}]}]}` |
| `speaking-data` | слова с занятий | `{"topics":[{"cat":"…","ru":"…","items":[{"en","ipa","ru","note?"}]}]}` |

Поле `note` (необязательное) — пометка-исправление, показывается золотой сноской
в списке и на обороте карточки.

### Добавить новую тему в Speaking (самое частое)

Дописать объект в массив `topics` блока `speaking-data`. Больше ничего менять не нужно:
счётчики, фильтр по темам, поиск, карточки и статистика подхватывают данные сами.

```json
{"cat":"HEALTH","ru":"Здоровье","items":[
  {"en":"work out","ipa":"/ˌwɜːk ˈaʊt/","ru":"тренироваться"},
  {"en":"newbie","ipa":"/ˈnjuːbi/","ru":"новичок","note":"Пишется newbie, а не newby."}
]}
```

Расписание дней строится автоматически: после каждых 3 уроков вставляется день
повторения, поэтому новый урок в `vocab` тоже не требует правок кода.

## Как хранится прогресс

`localStorage`, ключ `english_b1b2_progress` (тема оформления — `english_theme`).

```
{ v:2, lessons:{l0:{learned:[],score}}, reviews:{}, srs:{}, act:{}, streak:{}, history:[],
  lastDay, pb:{learned:[]}, sp:{learned:[]} }
```

`pb` — фразы (ключ = текст фразы), `sp` — Speaking (ключ = `"ТЕМА|english"`).
Если `localStorage` заблокирован, сайт переключается на память и показывает предупреждение.

## О чём легко забыть

- **Озвучки нет намеренно.** Пользователь просил убрать — не возвращать без спроса.
- **6 тем оформления** (кружки справа вверху) на CSS-переменных, по умолчанию `noche`
  (тёмная тёплая с фото Лондона). Новые элементы стилизуй через переменные `--accent`,
  `--surface`, `--text` и т. д., иначе сломается в светлых темах.
- **`midnight` — единственная тема с кнопками в обводке.** Все её правила скоуплены
  селектором `html[data-theme="midnight"]`; если задать их глобально, поедут четыре
  светлые темы. Там же специально прописаны `.match-btn.selected/.correct/.wrong` —
  общая обводка специфичнее базовых правил и перекрыла бы обратную связь в «Парах».
- **`color-scheme` задаётся на тему, а не глобально.** `dark` у `noche` и `midnight`,
  `light` у остальных четырёх. Без него на тёмной теме галочки в таблице, скроллбар
  и выбор файла остаются белыми.
- **Счётчики в подвале и в плашке «Фразы» вычисляются из данных** (`TOTAL_WORDS`,
  `PB_TOTAL`, `SP_TOTAL`, `PB_GROUPS.length`), а не записаны текстом. Раньше были
  захардкожены и протухали при каждом пополнении — не возвращай числа в разметку.
- **Список тем в разговорнике свёрнут** до `PB_CATS_SHOWN` (10) штук плюс кнопка
  «ещё N тем»: при 27 категориях полная строка чипов занимала четыре ряда.
  Выбранная тема всегда остаётся видна, даже если не попала в первые десять.
- **Панель вкладок липкая** (`.bar{position:sticky}`); класс `.stuck` вешает скролл-
  слушатель — он включает рамку и тень только когда панель реально прилипла.
- **На узком экране прячется колонка с номером, а не транскрипция** — она нужнее.
  У `td.ipa` в базе стоит `white-space:nowrap`, поэтому в мобильном медиазапросе
  перенос возвращается принудительно, иначе таблица вылезает за экран.
- **Слова первого урока продублированы статически** в `<tbody id="rows">` — чтобы
  таблица была видна даже без JS. Если меняешь урок 1, обнови и эту разметку.
- **Карточки: сбрасывать переворот только через `flipReset(el)`**, а не
  `classList.remove('flipped')` — иначе при переходе к следующей карточке полсекунды
  видно перевод (карточка плавно докручивается обратно).
- Интерфейс русский, контент английский. Транскрипция — британская.
- После правки JS прогони проверку синтаксиса, весь скрипт — одним куском:
  `node --check` по извлечённому `<script>`.
