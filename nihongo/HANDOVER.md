# Японский N5 — как продолжать работу над сайтом

Файл-инструкция для нового чата / другого ИИ. Прочитай целиком, прежде чем что-то менять.

## Что это

Тренажёр японского для Аристарха (уровень чуть ниже N5, занимается по «Минна но Нихонго»).
Сделан по образцу `italiano/` из репозитория https://github.com/Vladnes7/english-b1-b2 —
та же логика дней, SRS, карточек, пар и статистики, плюс японская специфика.

**Готовый сайт — один файл `index.html`**, но редактировать его руками не нужно:
он собирается из папки `src/`.

```
src/lessons1.json   уроки 1–5  (слова + фразы)
src/lessons2.json   уроки 6–10
src/grammar.json    темы грамматики по номеру урока учебника
src/extra.json      частицы (теория), упражнения на частицы, вежливо↔просто, диалог
src/template.html   CSS и разметка
src/app1.js         фуригана, спряжение, хранилище, вкладки «Слова» и «Грамматика»
src/app2.js         все упражнения, тест, повторение, прогресс, навигация
src/build.py        сборка: python3 src/build.py  →  index.html
```

## Пожелания Аристарха (из голосовых) — не терять

1. У новых слов — примеры в предложениях.
2. У глагола — группа, у прилагательного — い или な.
3. Упражнения: слова, карточки, пары, целые и устойчивые фразы, кандзи.
4. **Всё с кандзи — обязательно с фуриганой**: он пока не читает кандзи.
5. ます-форма и словарная, вежливая и простая речь, переделка форм (て-форма, прошедшее у прилагательных).
6. Короткие объяснения частиц (に, で, を…) и форм.
7. Связь с учебником «Минна но Нихонго».

## Формат данных

```json
{"jp":"食[た]べます","d":"食[た]べる","t":"v2","ru":"есть, кушать",
 "ex":"毎朝[まいあさ] パンを {食[た]べます}。","exru":"Каждое утро ем хлеб.","note":"необязательно"}
```

- **Фуригана**: чтение в `[]` сразу после кандзи: `日本語[にほんご]`. Кана и цифры без скобок.
  Скобки после каны не превращаются в фуригану (так специально пишут `どこ[へ]も`).
- `t`: `v1` `v2` `v3` (группы глаголов), `i`, `na`, `n`, `pron`, `q`, `adv`, `conj`, `suf`, `expr`, `other`.
- Глаголы: `jp` — ます-форма (как в учебнике), `d` — словарная. Все остальные формы
  **вычисляются** (`vbase` / `conjV` в app1.js), руками их не пишут.
- `な`-прилагательные хранятся без な: `"jp":"静[しず]か"`.
- В `ex` слово для упражнения «Пропуски» заключено в `{}` — ровно одна пара.
- `jp` должен быть уникален по всему сайту: это ключ SRS.
- В `ru` всё, что через запятую, — отдельные верные ответы в тесте; скобки игнорируются.

Добавить урок 11 = дописать объект в `lessons2.json`, темы — в `grammar.json` под ключом `"11"`,
упражнения на частицы — в `extra.json → pdrill` с `"l":11`. Код не трогать.

## Проверка после правок

После сборки прогони проверку данных: `node src/check.js index.html`. Она проверяет, что:
- у каждого слова есть `{пропуск}` и нет «висящих» скобок;
- ます-форма, вычисленная из `d`, совпадает с `jp` (так ловится неверная группа глагола);
- у каждой формы находится минимум 3 правдоподобных неверных варианта.

JS-синтаксис: `node --check` по содержимому `<script>`.

## О чём легко забыть

- **Ключ прогресса `nihongo_n5_progress` не менять**: все сайты на `vladnes7.github.io` делят один localStorage.
- **Озвучки нет** — в семье сайтов её убрали по просьбе пользователя. Для японского она
  была бы полезна, но добавлять только с разрешения.
- Ловушки в данных, о которых стоит помнить: 帰る и 切る — I группа; 見る, 起きる, 借りる, いる — II;
  きれい и 嫌い — な-прилагательные; いい → よくない/よかった; ある → ない; 行く → 行って; 来る читается く/き/こ.
- Кнопки-варианты рисуются через `askChoice(box, …)`; внутри ищи элементы через `box.querySelector`,
  а не `$()`: одинаковые id живут в нескольких скрытых панелях.
- Шрифты: Onest (русский), Klee One (японский — «учебниковые» формы каны), Shippori Mincho B1 (заголовок).
- Фото шапки — `hero.jpg` рядом с `index.html`; без него виден градиент-закат.
