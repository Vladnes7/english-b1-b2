# 日本語 · Японский N5 по «Минна но Нихонго»

Тренажёр японского для начинающих (чуть ниже N5): **10 уроков, 252 слова, 59 фраз**,
по урокам 1–10 учебника «みんなの日本語». Сделан по пожеланиям Аристарха.

Весь сайт — один файл `index.html` + фото `hero.jpg`. Ни сборки для запуска, ни бэкенда:
файл открывается двойным кликом. Прогресс хранится в браузере.

## Что внутри

| Вкладка | Что делает |
|---|---|
| **Слова** | Слово с фуриганой · чтение каной и русскими буквами · тип (группа глагола, い/な) · перевод и пример. Внизу — устойчивые фразы урока с пометкой «вежливо / с друзьями» |
| **Грамматика** | Темы урока со ссылкой на урок учебника · Частицы · Глаголы: формы (ます, 辞書形, ない, て, た) · Прилагательные · Вежливо и просто |
| **Практика** | Карточки и Пары (слова или фразы) · Пропуски · Кандзи (прочитай без фуриганы) · Частицы · Формы (переделай глагол/прилагательное) · Вежливо ↔ просто |
| **Тест** | Слова дня в обе стороны |
| **Повторить** | Ошибки возвращаются через 1, 3 и 7 дней |
| **Прогресс** | Статистика по словам и упражнениям, календарь, экспорт/импорт |

Расписание: 10 уроков, после каждых трёх — день повторения. Всего 13 дней.

## Как читать подсказки

- Над каждым кандзи — **фуригана** (чтение хираганой). Кнопка «ふりがな» её прячет — для самопроверки.
- Группы глаголов как в учебнике: **I** (う-глаголы), **II** (る-глаголы), **III** (する, 来る).
- У прилагательных — **い-прил.** или **な-прил.**; у な-прилагательных в таблице стоит «(な)».
- Нажми на слово в таблице — появятся его формы.
