# Итальянский A1 — как продолжать работу над сайтом

Файл-инструкция для нового чата / другого ИИ. Прочитай его целиком, прежде чем что-то менять.

## Что это

Тренажёр итальянской лексики для новичка. **Весь сайт — один самодостаточный файл
`index.html`** (~73 КБ): HTML, CSS, JS и словарь внутри. Никаких сборок, зависимостей
и внешних запросов, кроме шрифтов Google Fonts (без сети подставляются системные).

- Репозиторий: https://github.com/Vladnes7/english-b1-b2, папка `italiano/`
- Опубликован: https://vladnes7.github.io/english-b1-b2/italiano/
  (GitHub Pages, ветка `main`)

Сайт сделан из английского тренажёра, который лежит в корне того же репозитория
(`../index.html`). Логика — SRS, карточки, пары, пропуски, тесты, статистика — та же,
поэтому исправления полезно переносить между ними в обе стороны.

## Разделы

Учить · Практика (Карточки / Пары / Пропуски) · Тест · Повторить (SRS) · Прогресс.

Вкладок «Фразы» и «Speaking» из английской версии здесь **нет** — они вырезаны целиком
(и разметка, и CSS, и JS). Если понадобятся, проще перенести их из английского файла.

## Где лежат данные

Один JSON-блок внутри `index.html`: `<script id="vocab" type="application/json">`.

```json
{"lessons":[{"topic":"Тема урока","words":[
  {"en":"caffè","ipa":"каф-ФЭ","ru":"кофе (м)",
   "sentence":"Prendo un caffè, grazie.","strans":"Мне кофе, спасибо."}
]}]}
```

- `en` — **итальянское** слово. Имя поля осталось от английской версии, менять его нельзя:
  на нём завязаны `WORDMAP`, ключи SRS и разметка `<tbody id="rows">`.
- `ipa` — произношение русскими буквами, ударный слог ЗАГЛАВНЫМИ.
- `ru` — перевод. Род итальянского слова в скобках: `(м)` / `(ж)`.
  Всё после `(` и после запятой считается **альтернативным верным ответом** в тесте
  (см. `accepted()`), поэтому «дом» засчитывается для `casa` несмотря на пометку.
- `sentence` **обязан содержать слово из `en` дословно** — на этом работает режим
  «Пропуски»: слово вырезается из фразы регуляркой. Если написать `en:"mangiare"`,
  а во фразе будет `mangio` — пропуск не подставится.

### Добавить урок

Дописать объект в массив `lessons`. Больше ничего менять не нужно: количество дней,
расписание, счётчики и статистика считаются из длины данных.
Расписание строится само — после каждых 3 уроков вставляется день повторения
(литерал `%3` в цикле построения `SCHED`).

Исключение — два места, где числа зашиты в текст: подвал («100 базовых слов»)
и строка «20 слов в день» в шапке. Их правят руками.

## Как хранится прогресс

`localStorage`, ключ `italiano_a1_progress`.

```
{ v:2, lessons:{l0:{learned:[],score}}, reviews:{}, srs:{}, act:{}, streak:{}, history:[], lastDay }
```

**Ключ менять нельзя.** Он намеренно отличается от английского сайта
(`english_b1b2_progress`), и это не перестраховка: оба сайта раздаются с одного домена
`vladnes7.github.io`, а `localStorage` привязан к домену, а не к папке. Разные имена
ключей — единственное, что мешает сайтам затирать прогресс друг друга.

Если `localStorage` заблокирован (приватный режим, запрет cookie), сайт переключается
на память и показывает предупреждение.

## О чём легко забыть

- **Озвучки нет намеренно.** Пользователь просил убрать в английской версии — не возвращать без спроса.
- **Тема одна** — цвета флага Италии, переключателя тем нет (в английской версии их 5).
  Всё оформление — на CSS-переменных в блоке `html{}`: `--accent` зелёный `#009246`,
  `--accent-2` красный `#ce2b37`. Новые элементы стилизуй через переменные
  (`--surface`, `--text`, `--border`…), а не через жёсткие цвета.
- **Слова первого урока продублированы статически** в `<tbody id="rows">` — чтобы таблица
  была видна даже без JS. Если меняешь урок 1, обнови и эту разметку (5 колонок, `data-i`).
- **Карточки: сбрасывать переворот только через `flipReset(el)`**, а не
  `classList.remove('flipped')` — иначе при переходе к следующей карточке полсекунды
  виден перевод.
- **Регулярка пропуска не использует `\b`** — в английской версии использует. Причина:
  `\b` не срабатывает после букв с диакритикой (`caffè`, `città`, `tè`), и такие слова
  просто не вырезались бы из фразы. Здесь границы заданы через `\p{L}\p{N}` с флагом `u`.
- Интерфейс русский, контент итальянский.
- После правки JS прогони проверку синтаксиса, весь скрипт — одним куском:
  извлечь содержимое `<script>` и `node --check`.
