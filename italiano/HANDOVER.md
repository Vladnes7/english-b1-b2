# Итальянский A1 — как продолжать работу над сайтом

Файл-инструкция для нового чата / другого ИИ. Прочитай его целиком, прежде чем что-то менять.

## Что это

Тренажёр итальянского для новичка: слова, фразы, грамматика A1. **Готовый сайт — один файл
`index.html`** (HTML, CSS, JS и данные внутри). Внешние запросы — только шрифты Google Fonts.

- Репозиторий: https://github.com/Vladnes7/english-b1-b2, папка `italiano/`
- Опубликован: https://vladnes7.github.io/english-b1-b2/italiano/ (GitHub Pages, ветка `main`)

Сайт вырос из английского тренажёра в корне репозитория (`../index.html`): SRS, карточки, пары,
пропуски, тест и статистика там общие. Грамматика, табло спряжений и упражнения «Собери фразу»,
«Глаголы», «Артикли», «Правила» есть только здесь. Японский сайт `../nihongo/` устроен похоже.

## Разделы

Учить (слова + фразы урока + грамматика урока) · Грамматика (темы + табло спряжений) ·
Практика (Карточки / Пары / Пропуски / Собери фразу / Глаголы / Артикли / Правила) ·
Тест · Повторить (SRS) · Прогресс.

## Где лежат данные — `src/`

```
src/lessons.json   16 уроков: слова, фразы, id тем грамматики урока
src/grammar.json   31 тема грамматики
src/build.py       проверка данных + вшивание в index.html
```

**После любой правки данных:** `python3 italiano/src/build.py`. Скрипт проверяет данные, вычисляет
спряжения и артикли и заменяет содержимое `<script id="vocab" type="application/json">` в `index.html`.
Руками этот блок не править — перезапишется.

### Слово

```json
{"en":"vino","ipa":"ВИ-но","ru":"вино (м)","sentence":"Un bicchiere di vino rosso.",
 "strans":"Бокал красного вина.","t":"n","g":"m","pl":"vini"}
```

- `en` — **итальянское** слово (имя поля осталось от английской версии). Это ключ SRS: должно быть уникальным.
- `ipa` — произношение русскими буквами, ударный слог ЗАГЛАВНЫМИ.
- `ru` — перевод; всё через запятую, `;` и после `(` — отдельные верные ответы в тесте.
- `sentence` **обязан содержать `en` дословно** — на этом работает «Пропуски» (build.py проверит).
- `t` — тип: `n` (сущ.), `v` (глагол), `adj`, `adv`, `pron`, `q` (вопросительное), `num`, `prep`, `conj`, `expr`, `name`.
- Существительные: `g` — род `m`/`f`; `pl` — мн. число (нет поля — не исчисляется); `plg` — если во мн. числе
  род другой (`uovo → le uova`: `"plg":"f"`); `"only":"pl"` — слово живёт во мн. числе (`pantaloni`, `scarpe`).
  Артикли (`art`, `ind`, `artpl`) **вычисляет build.py**.
- Глаголы: спряжение (`conj`, группа `vg`) **вычисляет build.py**. `"isc":true` — глагол с -isc- (capire, finire).
  `"noconj":true` — не спрягать в упражнении (piovere, costare). Неправильные глаголы — словарь `IRREG` в build.py:
  новый неправильный глагол сначала добавь туда.

### Фраза урока

`{"it":"Che lavoro fai?","ru":"Кем ты работаешь?"}` — короткая (3–7 слов): из неё собирается упражнение
«Собери фразу» (разбивка по пробелам). Имена собственные внутри фразы пишутся с большой буквы — так
их узнаёт код.

### Тема грамматики

```json
{"id":"are","l":8,"title":"…","lead":"…","table":{"head":[…],"rows":[[…]]},"body":"…",
 "ex":[["Studio l'italiano.","Я учу итальянский."]],"tip":"…","verb":"parlare",
 "q":[{"q":"Io ___ a Roma. (abitare)","a":"abito","o":["abita","abiti"]}]}
```

- `l` — номер урока, с которого тема актуальна; тема должна быть и в `gram` этого урока.
- В `lead`, `body`, `tip`, `q` можно HTML. В таблице и примерах `**так**` — подсветка жёлтым.
- `q` — вопросы «Проверь себя» и упражнения «Правила»: `a` верный ответ, `o` неверные.
- `verb` — необязательно: кнопка «Все формы на табло».

### Добавить урок

Дописать объект в `lessons.json` (20 слов, 8 фраз, `gram`), темы — в `grammar.json`, запустить build.py.
Дни, расписание, счётчики и подвал считаются сами. Повторение вставляется после каждых 3 уроков.
**Не переставлять и не удалять старые уроки**: прогресс хранится по номеру урока (`l0`, `l1`…).

## Как хранится прогресс

`localStorage`, ключ `italiano_a1_progress`.

```
{ v:2, lessons:{l0:{learned:[],score}}, reviews:{}, srs:{}, act:{}, streak:{}, history:[], lastDay, drill:{} }
```

**Ключ менять нельзя.** Он намеренно отличается от английского сайта
(`english_b1b2_progress`), и это не перестраховка: оба сайта раздаются с одного домена
`vladnes7.github.io`, а `localStorage` привязан к домену, а не к папке. Разные имена
ключей — единственное, что мешает сайтам затирать прогресс друг друга.

Если `localStorage` заблокирован (приватный режим, запрет cookie), сайт переключается
на память и показывает предупреждение.

## Фон шапки: фотография поверх рисунка

`.hero-bg` задаёт **два слоя** одним свойством:

```css
background-image: url('hero.jpg'), url("data:image/svg+xml;charset=utf-8,…");
```

Верхний слой — файл `hero.jpg` рядом с `index.html`. Нижний — нарисованный на SVG
закат над Римом (Колизей, купола, пинии), вшитый в файл как data-URI, ~10 КБ.
Если `hero.jpg` нет, слой просто не рисуется и видно рисунок — фолбэк без единой
строчки JS.

**Чтобы поменять фотографию, достаточно положить в эту папку файл с именем ровно
`hero.jpg`.** Код трогать не нужно. Разумный размер — 1600–2000 px по ширине
и 300–500 КБ, иначе страница будет долго грузиться.

Поверх обоих слоёв лежит `.hero-bg::after` — тёмная градиентная вуаль. Она нужна,
чтобы белый заголовок читался на любой картинке; убирать её не стоит.

## О чём легко забыть

- **Озвучки нет намеренно.** Пользователь просил убрать в английской версии — не возвращать без спроса.
- **Тема одна, тёмная** — «римский закат», переключателя тем нет (в английской версии их 5).
  Всё оформление — на CSS-переменных в блоке `html{}`. Зелёный и красный флага там
  **осветлены**: `--accent:#17a35a`, `--accent-2:#e04352` вместо канонических
  `#009246` / `#CE2B37` — оригинальные на чёрном фоне не читаются. Новые элементы
  стилизуй через переменные (`--surface`, `--text`, `--border`…), а не жёсткими цветами.
- **`color-scheme:dark` на `html`** — не удалять. Без него системные контролы
  (галочки в таблице, скроллбар, выбор файла при импорте прогресса) остаются
  светлыми и режут глаз на тёмном фоне.
- **Все кнопки — в зелёной обводке**, это общее правило в начале блока кнопок.
  Оно идёт перед частными правилами, чтобы те могли что-то переопределить.
  Заливка зелёным — только у активной вкладки, главной кнопки `.btn` и выбранной
  карточки в «Парах». Отдельно заданы `.match-btn.correct` и `.match-btn.wrong`:
  на них держится обратная связь в упражнении, и они намеренно контрастнее обычной
  обводки — иначе правильный ответ не отличить от невыбранной кнопки.
- **Контент во всю ширину** — у `.wrap` нет `max-width`. В английской версии он 1400px.
- **Слова первого урока продублированы статически** в `<tbody id="rows">` — чтобы таблица
  была видна даже без JS. Если меняешь урок 1, обнови и эту разметку (5 колонок, `data-i`).
- **Табло спряжений** — сигнатурный элемент сайта (вокзальное табло). Цвета в `--flap-*`, шрифт
  Barlow Condensed. Жёлтым — окончание по правилу, розовым — неправильная форма.
- Результаты новых упражнений — `store.drill = {build, verbs, articles, rules}: {c, t}`.
- **Карточки: сбрасывать переворот только через `flipReset(el)`**, а не
  `classList.remove('flipped')` — иначе при переходе к следующей карточке полсекунды
  виден перевод.
- **Регулярка пропуска не использует `\b`** — в английской версии использует. Причина:
  `\b` не срабатывает после букв с диакритикой (`caffè`, `città`, `tè`), и такие слова
  просто не вырезались бы из фразы. Здесь границы заданы через `\p{L}\p{N}` с флагом `u`.
- Интерфейс русский, контент итальянский.
- После правки данных — `python3 src/build.py`. После правки JS прогони проверку синтаксиса, весь скрипт — одним куском:
  извлечь содержимое `<script>` и `node --check`.
