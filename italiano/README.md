# Итальянский с нуля · A1

Тренажёр итальянского для новичка: **16 уроков, 320 слов, 129 готовых фраз и 31 тема грамматики**
по программе A1 (темы и порядок — как в учебниках *Nuovo Espresso 1* и *Nuovissimo Progetto italiano 1*).

Открыть: **https://vladnes7.github.io/english-b1-b2/italiano/**

Весь сайт — один файл `index.html` + фото `hero.jpg`. Ни бэкенда, ни зависимостей: файл открывается
двойным кликом. Данные редактируются в `src/` и вшиваются в `index.html` командой `python3 src/build.py`.
Прогресс хранится в браузере.

## Что внутри

| Вкладка | Что делает |
|---|---|
| **Учить** | Таблица слов дня (с артиклем) · фразы урока · карточки с грамматикой урока |
| **Грамматика** | 31 тема с таблицами, примерами, «ловушками для русскоговорящих» и мини-проверкой · **табло спряжений** всех 48 глаголов |
| **Практика** | Карточки · Пары · Пропуски · **Собери фразу** · **Глаголы** (спряжение) · **Артикли** · **Правила** (вопросы по грамматике) |
| **Тест** | Опрос по словам дня в обе стороны: ит → рус и рус → ит |
| **Повторить** | Умное повторение (SRS): ошибки возвращаются через 1, 3 и 7 дней |
| **Прогресс** | Статистика, серия дней, календарь, результаты упражнений, экспорт/импорт |

## Как читать подсказки

- Произношение записано русскими буквами, **ЗАГЛАВНЫМИ выделен ударный слог**: `caffè → каф-ФЭ`.
- `(м)` и `(ж)` в переводе — род слова **в итальянском**: `il/lo` → м, `la` → ж.
  Он часто не совпадает с русским: `la casa` — дом, но женского рода.
- В полях ввода есть кнопки `à è é ì ò ù`. Ответ засчитывается и без диакритики:
  `caffe` = `caffè`.
