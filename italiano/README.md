# Итальянский с нуля · A1

Тренажёр итальянской лексики для полного новичка: **100 базовых слов**, 5 уроков по 20,
с произношением русскими буквами, примерами и умным повторением.

Открыть: **https://vladnes7.github.io/english-b1-b2/italiano/**

Весь сайт — один файл `index.html` (~73 КБ). Ни сборки, ни зависимостей, ни бэкенда:
файл открывается двойным кликом и работает офлайн. Прогресс хранится в браузере.

Лежит в папке `italiano/` репозитория [english-b1-b2](https://github.com/Vladnes7/english-b1-b2)
рядом с английским тренажёром B1–B2 — два независимых сайта, каждый со своим прогрессом.

## Что внутри

| Вкладка | Что делает |
|---|---|
| **Учить** | Таблица слов дня: слово · произношение · перевод · галочка |
| **Практика** | Карточки · Пары · Пропуски (вставить слово во фразу) |
| **Тест** | Опрос по словам дня в обе стороны: ит → рус и рус → ит |
| **Повторить** | Умное повторение (SRS): ошибки возвращаются через 1, 3 и 7 дней |
| **Прогресс** | Статистика, серия дней, календарь занятий, экспорт/импорт прогресса |

Расписание: 5 уроков, после каждых трёх — день повторения. Всего 6 дней.

1. Приветствия и вежливость
2. Люди и семья
3. Еда и напитки
4. Город, дом и дорога
5. Базовые слова и глаголы

## Как читать подсказки

- Произношение записано русскими буквами, **ЗАГЛАВНЫМИ выделен ударный слог**: `caffè → каф-ФЭ`.
- `(м)` и `(ж)` в переводе — род слова **в итальянском**: `il/lo` → м, `la` → ж.
  Он часто не совпадает с русским: `la casa` — дом, но женского рода.
- В полях ввода есть кнопки `à è é ì ò ù`. Ответ засчитывается и без диакритики:
  `caffe` = `caffè`.
